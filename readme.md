# LeetMirror 🪞

LeetMirror is a simple web app where you enter 
any LeetCode username and it shows how many 
Easy, Medium, and Hard problems they have solved
— with cool circular progress indicators.

## What it does
- Enter a LeetCode username → hit Search
- See solved problems in animated circles
- View total submission counts

## Built With
- HTML, CSS, JavaScript
- LeetCode API for fetching user data

## How to Run
Just open index.html in your browser — done!
